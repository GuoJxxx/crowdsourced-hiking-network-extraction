# Start the reproduction

1. Extract the complete ZIP and open its `TrailNetwork` folder.
2. Double-click `Start.cmd`.
3. In **Configuration**, browse to this computer's Python executable, MATLAB executable and JDK directory. Save the configuration.
4. Choose **Check installation** and confirm `ready: true`. Use **Install Python packages** if required, then check again.
5. In **Reproduction**, choose a method or manuscript item and select **Run selected**. Choose **Run all findings** for the complete workflow.
6. Open the computed products with **Open results**. Default outputs are under `Chicago/Results` and `StudyArea/Results` inside the extracted folder.

[README.md](README.md) covers software, configuration, experiments and run controls. [REPRODUCE.md](REPRODUCE.md) maps Tables 1-3 and A1, Figures 8-12 and the reported measures to the published inputs and computational steps.

The package includes the source code, input observations, parameter profiles and illustrated instructions. Select the software installed on the current computer through the configuration window. Python packages are installed into the selected Python environment.

Follow the eight illustrated steps at the start of [REPRODUCE.md](REPRODUCE.md) for the current window pages and their controls.
